# Visual Segmentation Trial: сегментация видео на сцены

Репозиторий содержит пайплайн для автоматической сегментации видеоряда на сцены с использованием различных визуальных признаков (гистограммы HSV, эмбеддинги CLIP и DINOv2), а также инструменты для оценки качества, кросс-валидации и визуализации результатов.

## Основные возможности

- **Детекция склеек (шотов).** PySceneDetect с кэшированием результатов в `data/shots/`.
- **Извлечение признаков (3 метода):**
  - **HSV** — цветовые гистограммы (быстрый, интерпретируемый);
  - **CLIP** — семантические эмбеддинги;
  - **DINOv2** — самоконтролируемые эмбеддинги для плотной локализации.
- **Группировка шотов.** Объединение шотов в сцены на основе косинусного сходства:
  - **Fixed** — фиксированный порог (оптимальный);
  - **Percentile** — адаптивный перцентильный порог.
- **Пост-обработка.** Опциональный фильтр по речи: если склейка попадает внутрь реплики, она удаляется.
- **Оценка качества.** Сравнение с Ground Truth по шотам с допуском ±1, расчёт Micro и Macro метрик (Precision, Recall, F1, TP/FP/FN).
- **Кросс-валидация.** Leave-One-Out (LOO) для честного подбора порогов.
- **Baselines.** Встроенные тривиальные методы (All Cuts, Grid).

##  Быстрый старт

### 1. Установка зависимостей

Убедитесь, что установлены Python 3.9+ и `ffmpeg` (необходим для корректной работы `faster-whisper`).

```bash
pip install -r requirements.txt
```

### 2. Подготовка данных

- Поместите исходные видео в `data/raw/`.
- Поместите эталонную разметку в `data/ground_truth/` (формат: `<video_name>.csv` с колонками `start_sec`, `end_sec`).

### 3. Запуск пайплайна

Предсказания с фиксированными порогами:

```bash
python src/main.py
```

С адаптивным перцентильным порогом:

```bash
python src/main.py --mode percentile --k 30.0
```

С речевым фильтром:

```bash
python src/main.py --speech
```

### 4. Оценка результатов

Сравнение всех методов (включая baseline'ы) и вывод таблицы:

```bash
python src/matchs/ev_all.py
```

### 5. Построение PR-кривой

```bash
python src/utils/plot_builder.py
```

## Конфигурация (`config.yaml`)

| Параметр | Назначение |
|---|---|
| `signature` | Параметры извлечения признаков (шаг кадров, бины для HSV) |
| `grouping.threshold` | Фиксированные пороги: HSV — 0.65, CLIP — 0.90, DINOv2 — 0.50 |
| `grouping.lookback` | Количество шотов для анализа при группировке |
| `grouping.min_duration` | Минимальная длительность сцены |

## Метрики

Оценка производится по шотам с допуском ±1 шот. Это исключает ложные срабатывания, когда метод ставит границу «где-то рядом» с реальной склейкой. Считаются Precision, Recall, F1 (Micro/Macro), а также абсолютные TP, FP, FN.

##  Ключевые результаты

- **Fixed-пороги** (подобранные через LOO) дали наилучший баланс: F1 ≈ 0.67–0.72.
- **Percentile-пороги** слишком агрессивны для CLIP/DINO, что приводит к падению Recall.
- **Речевой фильтр** повысил точность (Precision), но снизил полноту (Recall), так как в коротких отрывках диалоги идут непрерывно.
