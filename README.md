# Visual Segmentation Trial: Сегментация видео на сцены

Репозиторий содержит пайплайн для автоматической сегментации видеоряда на сцены с использованием различных визуальных признаков: гистограмм HSV, эмбеддингов CLIP и DINOv2.

Проект также включает инструменты для оценки качества, кросс-валидации и визуализации результатов.

##  Основные возможности

- **Детекция склеек (шотов):** PySceneDetect с кэшированием результатов в `data/shots/`.
- **Извлечение признаков (3 метода):**
  - **HSV:** цветовые гистограммы (быстрый и интерпретируемый метод).
  - **CLIP:** семантические эмбеддинги.
  - **DINOv2:** самоконтролируемые эмбеддинги.
- **Группировка шотов:** объединение шотов в сцены на основе сходства (Fixed или Percentile threshold).
- **Постобработка:** опциональный фильтр по речи (Silero VAD, штраф за пересечение склейки).
- **Оценка качества:** единая функция `SceneEvaluator` с допуском 0, ±1 шот или N секунд. Рассчитываются Micro и Macro метрики: Precision, Recall, F1, TP/FP/FN.
- **Кросс-валидация:** Leave-One-Out (LOO) для подбора порогов.
- **Baselines:** тривиальные методы `All Cuts` и `Grid`.

## 🚀 Быстрый старт

### 1. Установка

Убедитесь, что установлены Python 3.10+ и `ffmpeg` (для VAD).

Установите зависимости:

```bash
pip install -r requirements.txt
```

### 2. Подготовка данных

1. Поместите видеофайлы в `data/raw/` (например, `1.mp4`, `2.mp4`).
2. Поместите эталонную разметку в `data/ground_truth/` (CSV-файлы с колонками `start_sec`, `end_sec`).

### 3. Запуск полного пайплайна

```bash
python src/run_pipeline.py
```

Скрипт последовательно выполняет следующие действия:

1. Запускает LOO-кросс-валидацию (`cv_threshold.py`) и сохраняет лог в `results/logs/01_loo.txt`.
2. Ожидает обновления порогов в `config.yaml` (необходимо нажать Enter).
3. Генерирует предсказания (`main.py`).
4. Создаёт baseline-результаты (`baselines.py`).
5. Рассчитывает метрики (`ev_all.py`).
6. Строит графики (`plot_run.py`).

##  Метрики оценки

Основная метрика — **точное совпадение (допуск 0 шотов)**. Допуск ±1 используется только для сравнения с baseline-методами.

- **Micro:** суммарные значения TP, FP и FN по всему корпусу.
- **Macro:** среднее значение метрик по отдельным видео.

Дедупликация при оценке **не применяется**: она должна быть частью алгоритма сегментации, а не функции оценки.

##  Ограничения адаптивного порога

В текущей реализации адаптивный порог (Percentile) вычисляется по сходствам соседних шотов, а решение о наличии границы принимается на основе максимума сходства с последними `lookback` шотами.

Это эвристический подход, который не гарантирует точную долю границ.

В финальных экспериментах использовался **фиксированный порог**, подобранный с помощью Leave-One-Out кросс-валидации (LOO), поскольку он показал более стабильные результаты на всех датасетах.

##  Результаты экспериментов

### 1. Rai Scuola

*Документальные фильмы и ток-шоу, 10 видео.*

| Метод | Precision | Recall | F1 |
|:---|---:|---:|---:|
| All Cuts | 0.12 | 0.92 | 0.22 |
| CLIP | 0.22 | 0.55 | 0.31 |
| DINOv2 | 0.26 | 0.51 | **0.35** |
| HSV | 0.40 | 0.03 | 0.06 |
| Grid | 0.13 | 0.21 | 0.16 |

**Вывод:** на документальном контенте Rai Scuola наилучший результат показал DINOv2 с F1 = 0.35. HSV оказался малоэффективен из-за плавных переходов между сценами. Речевой фильтр снижает Recall при наличии непрерывного монолога.

### 2. OVSD

*21 видео, включая полнометражные фильмы.*

| Метод | Precision | Recall | F1 |
|:---|---:|---:|---:|
| All Cuts | 0.07 | 0.96 | 0.13 |
| CLIP | 0.12 | 0.52 | 0.19 |
| DINOv2 | 0.16 | 0.50 | 0.25 |
| HSV | 0.25 | 0.40 | **0.31** |
| Grid | 0.13 | 0.43 | 0.19 |

**Вывод:** на OVSD, содержащем большое количество анимации и коротких клипов, наилучший F1 = 0.31 показал HSV. DINOv2 (0.25) и CLIP (0.19) уступили из-за семантической однородности анимационных сцен.

### 3. BBC Planet Earth

*11 серий документального кино.*

| Метод | Precision | Recall | F1 |
|:---|---:|---:|---:|
| All Cuts | 0.93 | 0.42 | **0.58** |
| CLIP | 0.96 | 0.40 | 0.56 |
| DINOv2 | 0.98 | 0.23 | 0.37 |
| HSV | 0.98 | 0.37 | 0.54 |
| Grid | 0.96 | 0.19 | 0.32 |

**Вывод:** на BBC разметка `fixed.zip` оказалась разметкой **склеек, а не смысловых сцен**. Поэтому тривиальный метод All Cuts превзошёл нейросетевые методы с F1 = 0.58.

##  Общие выводы

1. **Выбор метода зависит от типа контента:**
   - Документальные фильмы — DINOv2.
   - Анимация и короткие клипы — HSV.
   - Разметка склеек вместо смысловых сцен — All Cuts.

2. **Универсального метода сегментации нет.** Нейросетевые подходы не всегда превосходят тривиальные baseline-методы. Это важный экспериментальный результат, демонстрирующий зависимость качества алгоритма от особенностей данных.

3. **Речевой фильтр (VAD) требует аккуратного применения.** На документальном контенте с непрерывным монологом его использование может снижать Recall в 2–3 раза.
