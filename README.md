# Visual Segmentation Trial: Сегментация видео на сцены

Данный репозиторий содержит пайплайн для автоматической сегментации видеоряда на сцены с использованием различных визуальных признаков (гистограммы HSV, эмбеддинги CLIP и DINOv2), а также инструменты для оценки качества, кросс-валидации и визуализации результатов.

## 📋 Основные возможности

*   **Детекция склеек (шотов):** Использование `PySceneDetect` с кэшированием результатов.
*   **Извлечение признаков (3 метода):**
    *   **HSV:** Цветовые гистограммы (быстрый, интерпретируемый).
    *   **CLIP:** Семантические эмбеддинги.
    *   **DINOv2:** Самоконтролируемые эмбеддинги для плотной локализации.
*   **Группировка шотов:** Объединение шотов в сцены на основе сходства признаков (Fixed или Percentile порог).
*   **Пост-обработка:** Опциональный фильтр по речи (если слово пересекает склейку, граница штрафуется).
*   **Оценка качества:** Единая функция оценки (допуск 0, 1 шот или N секунд), расчет Micro и Macro метрик.
*   **Кросс-валидация:** Leave-One-Out (LOO) для честного подбора порогов.
*   **Baselines:** Встроенные тривиальные методы (All Cuts, Grid).
